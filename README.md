## 🧠 What I'm working on

- **Localizing electrodes in the brain from the signals they record.** Geometry-aware self-supervised foundation models trained on raw Neuropixels LFP. This work produced two NeurIPS 2026 papers.
- **High-speed voltage imaging.** With Prof. Shy Shoham, I built the image reconstruction for a 440 Hz two-photon microscope (OJAMI) and a self-supervised denoiser that recovers individual action potentials from shot noise without clean ground truth.
